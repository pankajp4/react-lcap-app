      A component that provides a global notification system using Material-UI's Snackbar and Alert components. It connects to Redux to manage notification state.

      Returns Element

      Component

      Remarks

      This component does not accept any props as it manages its state entirely through Redux. To show notifications, dispatch actions from the notification slice.

      Example

      // In your app's root component:
      <NotificationSystem />

      // To show a notification from anywhere in your app:
      dispatch(showNotification({ message: "Success!", severity: "success" }));

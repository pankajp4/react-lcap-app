    Interface BuilderComponent

    Runtime component instance with position and size information

    Since

    1.0.0

    Remarks

    Extends ComponentConfig to add:

    • Unique identifier
    • Position coordinates
    • Dimensions
    • Runtime styling

    This interface represents a component instance in the form canvas, combining the static configuration with runtime properties.

    Example

    const textboxInstance: BuilderComponent = {
      id: "text-1",
      type: "textbox",
      category: "input",
      label: "Name",
      icon: "text_fields",
      x: 100,
      y: 200,
      width: 200,
      height: 40,
      props: {
        placeholder: "Enter name"
      },
      style: {
        backgroundColor: "#ffffff",
        fontSize: 16
      }
    };
